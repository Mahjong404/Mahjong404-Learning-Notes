<font color="#f79646">含义：初始</font>
<font color="#f79646">变体：无</font>
<font color="#f79646">来源：法语单词naïf（意为natural或ingenuous，即自然的或天然的、天生的）</font>
<font color="#f79646">用途：构成初始相关词汇</font>

naive T cell 初始T细胞，幼稚T细胞（一种尚未接触到特定病原体或抗原的T细胞，因此能够发生初级免疫反应） 
naive immunity 初始免疫力（存在于尚未暴露于特定病原体或抗原的个体中的自然免疫力）
naive virus 初始病毒（一种尚未感染宿主细胞的病毒，因此能够感染易感宿主）
naive host 初始宿主（尚未接触过某种病原体或抗原的个体，因此对该病原体或抗原缺乏免疫力）
naive state 初始状态（对某一特定病原体或抗原没有事先接触或免疫的状态）
naive patient 尚未接触过某种病原体或抗原的病人（因此对该病原体或抗原缺乏免疫力）
naive infection 发生在尚未接触过特定病原体或抗原的人身上的感染
naive vaccinee 尚未接种某种特定疫苗的人，因此对该疫苗所针对的病原体或抗原缺乏免疫力
naive herd 尚未接触过特定病原体或抗原的群体，因此对该病原体或抗原缺乏免疫力
naive antigen 一个个体或群体的免疫系统还没有遇到的抗原
naive memory cell 一种记忆细胞，尚未通过接触特定的病原体或抗原而被激活，因此缺乏进行二次免疫反应的能力
naive lymphocyte pool 存在于尚未暴露于特定病原体或抗原的个体中的淋巴细胞（包括T细胞和B细胞）的总群体
naive specificity 尚未通过接触特定的病原体或抗原来确定的免疫反应的特异性
